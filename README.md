## Instalar

1. Descarga `winy-debug.apk` desde el enlace superior en tu teléfono.
2. Abre el archivo desde Descargas. Si Android lo solicita, autoriza instalar aplicaciones desde ese navegador o gestor de archivos.
3. Instala Winy y elige a tu compañero.

Requiere **Android 8.0 o superior**, con **Android System WebView actualizado**. No necesitas publicar el entorno de ChatGPT para descargar este archivo.

Si el enlace directo no inicia la descarga, abre [el archivo en GitHub](https://github.com/melendezzz26/winy/blob/winy-apk-prueba/winy-debug.apk) y pulsa **Download raw file** (el icono de descarga).
